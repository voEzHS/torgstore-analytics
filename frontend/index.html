План и выручка по периодам
Каждый месяц — отдельные цифры

Для каждого периода укажи план продаж и, если нужно, общую выручку компании вручную (из 1С или другой системы учёта). Это позволит корректно считать % выполнения плана и долю рекламной выручки. Если оставить «Общую выручку» пустой — сайт подставит вместо неё автосумму накладных (реальные деньги по кассе, Алматы·Розница) за этот период, если они загружены; иначе будет использована рекламная выручка из CRM.
